## The entry

> The nursery camera saved a clip of the empty crib rocking, and the timestamp is eleven minutes from now.

## Run

`main.ts` writes exactly one line of horror to `/output/entry.txt`. Deterministic, Node built-ins only, no network.

```sh
node main.ts
```
